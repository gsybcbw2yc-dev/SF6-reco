## 7. セキュリティ

Buckler Cookieは既存の GitHub Secret `BUCKLER_ID` に残す。cron-job.orgには渡さない。外部ジョブを呼ぶためには、本人が **SF6-recoだけを対象にした Actions: Read and write の fine-grained personal access token** を作り、cron-job.org の `Authorization` ヘッダーに設定する。Actions write はワークフロー起動以外のActions操作も可能な権限であり、外部サービスの保管とアカウント防護を前提とする。トークンをチャットや公開ファイルへ貼らない。期限を決めて更新し、不要になればGitHubで失効させる。

公開されるのは観測値、日時、実行結果、秘密を含まないエラー分類。非公開なのはCookie、外部サービスの認証トークン、Bucklerの応答本文。実行時入力が予期しない形式でも値を公開ログに出さない。`workflow_dispatch` への成功応答204は起動受理に過ぎず、収集の成功はActionsジョブと `runs.json` で別途確認する。
