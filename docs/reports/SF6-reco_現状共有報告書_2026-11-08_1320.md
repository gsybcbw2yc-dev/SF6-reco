- 公開 `history.json` は観測日時・キャラクター・フェーズ・MR/LP・前回との差分・観測種別を保存。今回のUI変更によるスキーマ移行なし。2026-11-08 13:16 JST頃に7件を確認。
- `runs.json` は成功・失敗・スキップ、トリガー、実行ID、開始・終了時刻、取得キャラクター数を保存。同時点14件。`external_dispatch` の成功を3回確認。
- `status.json` は最新値、最後の取得成功・試行・レーティング変動、認証状態、安全なエラー情報を保存。今回の変更は読み取り専用の画面処理であり履歴の削除・補完は行っていない。
- 収集同時実行は既存のActions `concurrency: sf6-collect` と25分以内の重複抑制で制御。今回の変更はこの部分を変更していない。観測されなかった過去値は推測しない。
- GitHub Pagesとブラウザのキャッシュは反映までの遅延要因になり得る。JSONは時刻付きURLおよび no-store で確認するが、GitHub Pages側の公開完了前には新データを表示できない。
