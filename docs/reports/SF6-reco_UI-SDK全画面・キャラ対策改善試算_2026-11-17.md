# SF6-reco UI SDK 全画面展開・キャラ対策改善試算（2026-11-17 JST）

## 実装
- ヘッダーの「AI操作を有効にする」から全画面共通のSDKモードを起動。既存のWeb Componentsバンドル 0.1.0-beta.3を遅延読込し、16個の選択メニューを対応させる。既存ネイティブセレクトを正とし、自動取得・分析・通常UIを変更しない。従来モードに復帰可能。
- WebMCP対応ブラウザに `sf6_dashboard_state`、`navigate`、`set_filter`、`chart_layer`、`page`、`report`（すべて `sf6_dashboard_` 接頭辞）を登録。画面/分析/履歴/詳細分析のタブ、集計期間、グラフ表示、ページ移動、選択条件と表示結果の取得。非対応環境は通常操作・内部ブリッジを利用可能。権限は表示・集計のみ、非表示画面の操作・未定義値を拒否、認証情報・データ変更・削除・書出し操作は公開しない。無効化時登録解除。サイト内AIチャットや自動操作の常時実行ではない。
- 分析 → 対戦互角MR → キャラ対策によるMR改善シミュレーション。自分キャラ・ACT連動。相手キャラ、+5/+10/+20/+30ポイントまたは50%目標、50/100/200/500試合を切り替え。
- 同ACTかつ双方の対戦前MRがあり勝敗既知のランクマッチを使用。期待差分＝総試合数×相手キャラとの遭遇率×勝率差×（実測/推定の平均勝利MR＋平均敗北MR絶対値）。勝敗別の差分算定率70%以上かつ各5件以上を要求。不足時は同キャラ・ACT全戦の同条件各10件以上を使用し明記。対象10試合未満は保留、20試合未満は参考。条件付きシナリオであり実際の上昇予測ではない。

## 検証
- 全8本のCJSテスト、既存SDK pilot、全画面SDKの実バンドル＋happy-domテスト合格。WebMCP登録は模擬API、選択値変更・同期、拒否・状態保持、全画面遷移、ネイティブ復帰、試算結果を確認。
- 最新取得済み1072試合・716定期観測から、豪鬼Act14の分析適格574試合を抽出。豪鬼同キャラ戦62試合・26勝（41.9%）、遭遇率10.8%、差分61件。勝率+20pt・今後100試合固定なら改善+33.6 MR（参考）。実機iPad Safariは未検証。
- 既存の収集データ、認証情報、収集スケジュールは変更しない。
