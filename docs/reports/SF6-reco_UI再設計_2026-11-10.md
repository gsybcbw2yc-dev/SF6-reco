# SF6-reco UI/UX再設計 実装報告書
更新日: 2026年11月10日（JST）

## 目的と結論
機能追加によりMR/LP、試合履歴、時間帯分析、詳細分析、データ管理が縦長の1ページに集中していた問題を改善するため、**主要画面を4つに分離**し、必要な分析だけを選択表示する情報設計へ移行した。旧データや集計ロジックを削除せず、既存の無料 GitHub Actions + Pages 構成を維持した。

## 新しい情報設計（ワイヤーフレーム）
1. **概要**：小型ヘッダー／4画面ナビ／MR（最優先）・LP・最終同期時刻／MR・LP推移／期間サマリー
2. **対戦履歴**：MATCH HISTORY・SESSIONS・MATCHUPSの3タブ／期間・モード・キャラ・操作タイプは折りたたみ可能な「表示条件」内／キャラ相性横棒は維持
3. **分析**：「詳細分析」「時間帯・曜日」「MR増減速度」の3分類で切り替え。「詳細分析」内は既存の4分析タブ（連敗後、相手MR差、セッション内、直近20/50/100）を継続
4. **データ管理**：収集状態、異常・鮮度、手動更新、CSV/JSON書き出し、実行履歴情報

各画面は一度に1つのみ表示。iPhoneでは上部4タブを均等幅にし、MRを大きな主役カード、LPと同期を2つの補助カードとする。iPad/デスクトップでは適切に2列グラフを維持。

## ビジュアルデザイン
- 深いネイビー系のダーク基調、彩度を抑えた紫アクセント。シアンはLP、緑/赤は勝敗など意味のある数値に限定
- 大きな販促風ヒーローを撤去して、明快な「パフォーマンス」見出しへ
- MRを最も大きく表示し、細かなサマリー・補助説明は二次階層に移動
- 余白・角丸・境界線・タイポグラフィの規則を統一し、同じようなカードが延々と続く状態を軽減
- グローバルナビゲーションをsticky表示。分析ジャンルはサブナビに分離
- 対戦詳細フィルタは`details/summary`による開閉式。iOS Safariを考慮した最小タッチ高とレスポンシブCSS
- シンプルな動きとフォーカスリング、reduced motionを考慮

## 変更ファイル
- `web/index.html`：元の各コンテンツ・ID・フィルタ・スクリプトを維持しつつ、新4画面へDOMを再配置
- `web/view-navigation.js`（追加）：画面・分析タブ切替、aria-selected/hidden、矢印・Home・Endキー、選択状態保持
- `web/design-system.css`（追加）：旧コンポーネントCSSの後に読み込む新しいデザインレイヤー。既存グラフや計算のスタイルは安全に維持
- `tests/test_view_navigation.cjs`（追加）：1画面表示、タブ、キーボード、内側タブ状態保持の回帰試験
- `.github/workflows/collect.yml`：Node回帰テストに追加

既存`web/app.js`、`web/matches-ui.js`、`web/time-analysis-ui.js`の機能ロジックは**変更なし**。MR/LPや月別試合データの収集JSONは加工・削除していない。
